# 沪深 300 真实数据目录

运行 `labs/alphalens/download_tushare_csi300.py` 后，本目录会生成：

- `csi300_qfq_close_2021_2025.csv`：2021 至 2025 年的沪深 300 股票前复权收盘价宽表，行是交易日，列是股票代码；三个主程序直接使用该文件。
- `csi300_constituent_weights_202512.csv`：2025 年末指数成分股和权重，用于确定股票池。
- `data_quality.csv`：逐只股票的起止日期、记录数和缺失情况，便于检查下载质量。
- `metadata.json`：接口、日期范围、复权方式和下载参数说明。

这些文件来自用户自己的 Tushare 账户，可能受到数据授权条款约束，因此默认被 `.gitignore` 排除，不随公开 GitHub 仓库发布。

前复权价格会随着查询时使用的复权基准日变化，可能与行情软件在另一天查看的历史前复权价格不同。比较价格时应同时确认股票代码、交易日、复权类型和复权基准日。
